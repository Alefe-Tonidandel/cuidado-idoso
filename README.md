# ❤️ Cuidado com Amor

App de acompanhamento de saúde para idosos — especialmente desenvolvido para famílias que cuidam de pacientes com Síndrome de Lewy.

## Como usar

Acesse o link do GitHub Pages e instale no celular como app.

## Arquivos

- `index.html` — app principal (renomeie o cuidado_com_amor.html para isso)
- `sw.js` — service worker (deixar na mesma pasta)

## Instalação no celular

**Android:** Banner aparece automaticamente no Chrome após alguns segundos.  
**iPhone:** Safari → Compartilhar ⬆️ → Adicionar à Tela de Início.
